# ASYQ ARENA

ASYQ ARENA — браузерная 2D-игра, созданная на основе казахской национальной игры «Асық ату».

Главная цель проекта — показать традиционную игру в современном цифровом формате и сделать её понятной для новых игроков.

## 🎮 Как играть

Игрок управляет сақа и старается выбить асыки за пределы белого круга.

Для победы нужно выбить 8 асыков за 7 бросков.

Перед броском игрок:
1. выбирает направление;
2. подтверждает угол;
3. выбирает силу броска;
4. выполняет удар.

В игре также есть красный запрещённый асық. Если он полностью покинет круг, игрок проигрывает.

## ✨ Возможности

- Физика столкновений асыков
- Рикошеты и столкновения нескольких асыков
- Система силы броска
- PERFECT-бросок
- Интерактивное обучение
- Русский, казахский и английский языки
- Магазин и скины для сақа
- Разные оформления игровой площадки
- Локальный рейтинг и статистика

Скины являются только визуальными и не дают преимущества в игре.

## 👥 Для кого эта игра?

ASYQ ARENA предназначена для детей, подростков и взрослых. Игра помогает легко познакомиться с казахской национальной игрой «Асық ату», изучить её основные правила и попробовать сыграть в цифровом формате.
