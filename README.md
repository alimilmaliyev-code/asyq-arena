# ASYQ ARENA

**ASYQ ARENA** — браузерная 2D-адаптация казахской традиционной игры **асық ату**. Проект сделан так, чтобы человек, который раньше не играл в асық, мог понять основные принципы через короткое обучение и сразу попробовать механику в браузере.

## Для кого проект

Игра рассчитана на школьников, студентов и всех пользователей, которым интересны казахские национальные игры. Главная задача проекта — представить асық ату в понятном современном цифровом формате, сохранив идею прицеливания, силы броска, выбивания асыков и рикошетов.

## Правила этой версии

В центре игрового поля находятся асыки, окружённые белой границей. Игрок бросает **сақа** и старается полностью выбить обычные асыки за границу.

В основной соревновательной версии цель — выбить **8 асыков максимум за 7 бросков**. Один асық отмечен красным цветом и является **запретной целью**: если он полностью покидает круг — в том числе после прямого удара, рикошета или цепного столкновения — игрок проигрывает.

Перед броском игрок:
1. выбирает направление мышью или касанием;
2. подтверждает угол;
3. ловит нужное значение на движущейся шкале силы;
4. нажимает кнопку удара.

Сила меняется от **25 до 150**. Слабые броски обычно точнее. Сильные броски мощнее, но имеют больший риск отклонения. Центральная зона `150` сделана узкой, а попадание в её точный центр даёт `PERFECT`.

Сақа движется не только по поверхности: у броска есть визуальная высота и дуга. При сильном броске сақа может пройти над асыком слишком высоко и **перелететь его без столкновения**.

Поддерживаются физические **Multi-Hit** и цепные рикошеты: один бросок может столкнуть несколько близких асыков, а выбитый асық может передать импульс следующему.

## Адаптация для браузера

Традиционная игра требует физического броска рукой, поэтому в браузерной версии навык разделён на две понятные части: **направление** и **тайминг силы**. Это позволяет сохранить элемент точности, но сделать управление удобным для мыши и сенсорного экрана.

Физика рассчитывается в плоскости игрового поля: положение, скорость, импульс, трение и столкновения объектов. Дополнительная вертикальная координата используется для прыжка сақа и проверки перелёта над целью.

После броска игра ждёт завершения движения объектов и только затем подсчитывает результат и начинает следующий ход.

## Обучение нового игрока

При первом запуске открывается пошаговое обучение. Пользователь узнаёт цель игры, правило красного асыка, управление направлением и шкалой силы.

В финале обучения кнопка **«ПОПРОБОВАТЬ»** запускает интерактивную тренировку. Игрок должен самостоятельно:
- навести стрелку;
- подтвердить направление;
- выбрать силу;
- выполнить бросок.

Подсказки переключаются вместе с действиями игрока. После тренировочного броска обучение считается завершённым и сохраняется в `localStorage`. Его можно снова открыть через кнопку **«? КАК ИГРАТЬ»**.

## Технологии

- HTML5
- CSS3
- Vanilla JavaScript
- HTML5 Canvas 2D
- `requestAnimationFrame` для анимации
- собственная 2D-физика столкновений и рикошетов
- `localStorage` для локального сохранения состояния обучения

Проект не требует фреймворка, сборщика, сервера или базы данных.

## Запуск локально

Самый простой вариант — открыть `index.html` в современном браузере.

Для запуска через локальный сервер:

```bash
python3 -m http.server 8000
```

После этого открыть в браузере:

```text
http://localhost:8000
```

Команду нужно запускать из папки `asyq-game`.

Основная игровая логика, интерфейс и механика собраны непосредственно для этого проекта. В проекте нет подключённого игрового движка или готовой физической библиотеки.

Если перед финальной сдачей будут добавлены сторонние изображения, шрифты, звуки, библиотеки или другие ресурсы, здесь необходимо указать их название, автора/источник и условия лицензии.

## Известные ограничения

- Физика является игровой 2D-аппроксимацией, а не точной симуляцией реального броска асық.
- Поведение прыжка и перелёта настроено для игрового баланса.
- Прогресс обучения хранится локально в браузере и не синхронизируется между устройствами.
- В текущей версии нет сетевого мультиплеера и серверной системы аккаунтов.
- На устройствах с сильно отличающимися размерами экрана визуальное расположение элементов может немного отличаться.
- Результат броска зависит от настроенных игровых коэффициентов и не предназначен для воспроизведения реальных физических измерений.
